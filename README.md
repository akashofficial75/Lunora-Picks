# ✦ Lunora Picks

**Lunora Picks** is a modern and aesthetic product discovery website designed to showcase handpicked finds, trending products, and everyday essentials in a clean and engaging interface.

The website focuses on a **minimal, premium, and user-friendly experience**, making it easy for visitors to explore products and discover items worth adding to their wishlist.

### ✨ Features

* Modern & aesthetic UI
* Responsive design for all devices
* Curated product collections
* Clean product showcase
* Smooth and intuitive navigation
* Pinterest-friendly visual presentation
* Mobile, tablet & desktop optimized

### 🛠️ Tech Stack

**HTML • CSS • JavaScript**
